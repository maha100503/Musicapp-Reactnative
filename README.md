# Musicapp-Reactnative
Dive into MusicApp—a sleek React Native player for seamless local library vibes. Tab through songs, artists, albums &amp; faves with Redux state smarts, react-native-track-player playback, and Material Tabs navigation. Adaptive themes, AsyncStorage favorites, quick search. Clone, npm install, grant perms &amp; groove on!
=======
MusicApp React Native: Your Offline Music Companion:

Dive into MusicApp, a polished React Native music player designed for seamless offline listening. Built from the ground up, it transforms your device's local audio library into an intuitive, tabbed browsing experience. Whether you're shuffling through all songs, exploring by artist, curating albums, or revisiting favorites, this app keeps the rhythm flowing without interruptions.

Key Features:

Smart Library Scanning: Effortlessly fetches and organizes your MP3s, FLACs, and more using react-native-get-music-files. Reverse-chronological sorting ensures your latest additions are front and center.
Tabbed Navigation: Material Top Tabs for Songs, Artists, Albums, and Favourites—customized with a vibrant pink accent (#E82255) and adaptive dark/light themes via useColorScheme.
Advanced Playback: Leverages react-native-track-player for background audio, precise controls, and smooth transitions. Search functionality navigates to hidden gems in seconds.
Favorites Persistence: Toggle songs into a dedicated list, saved via AsyncStorage for instant recall across sessions.
User-Centric Design: Custom header with play icon branding, search button, and a persistent bottom player. Permissions are handled gracefully on Android, with splash screen polish.
